# Invitación de XV años de Mia

Sitio estático (estilo disco glam) listo para Vercel.

## Datos editables

- **Dirección, salón y WhatsApp:** objeto `CONFIG` al inicio de `script.js`. Al poner la dirección se actualizan el texto, el mapa de Google, el botón "Abrir en Google Maps" y el evento de calendario.
- **Música:** pega el link de Spotify (canción, playlist o álbum) en `CONFIG.spotify` en `script.js`.
- **Foto de la polaroid:** guarda la foto como `foto-mia.jpg` en esta carpeta. Si no existe, se muestra un diseño de respaldo.
- **Wishlist:** lista `<ul class="gifts">` en `index.html`.

## Publicación en Vercel

1. Entra a [vercel.com/new](https://vercel.com/new) e inicia sesión.
2. Importa la carpeta `Invitacion Mia` (o súbela a un repositorio de GitHub y selecciónalo desde Vercel).
3. Vercel detectará el sitio como estático. No se requieren comandos de compilación.
4. Pulsa **Deploy** y comparte el enlace por WhatsApp.
